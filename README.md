# 4. Rules
> There are rules for the learning and solving process, they are extremely strict for an important reason, which are:
1. The use of ANY AI model is strictly forbidden, you are never allowed to use AI for whatever reason while studying nor while solving labs, any attempt of usage will be noticed immediately. EVEN if using the AI model to help you understand a concept in the course
	- What you can do instead is research the internet for the idea that's said to learn more about it, watch a video, read a ___research paper___ (NOT AN INFLUENCER OR AN INDIVIDUAL'S ARTICLE)
	- If you're extremely stuck, search the internet with questions like (how to use X to exploit Y) not like (How to get into Y)
2. You should finish AT LEAST one lab everyday, no matter what the difficulty is that you've chosen, this also reflects to your credit and reputation on HackTheBox
3. NEVER skip courses just to finish them
